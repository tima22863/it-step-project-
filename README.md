# ChitKvest-RandomPlayers

## Опис

**ChitKvest-RandomPlayers** — це програма для випадкового розподілу гравців по командах або завданнях у форматі квесту.

## Системні вимоги

- **ОС:** Windows 7 / 8 / 10 / 11
- Додаткове встановлення не потрібне — програма є самостійним виконуваним файлом

## Інструкція по запуску

### Спосіб 1: Через провідник Windows

1. Завантажте файл `ChitKvest-RandomPlayers.exe` з цього репозиторію
2. Збережіть файл у будь-яку зручну папку на вашому комп'ютері
3. Двічі клікніть на файл `ChitKvest-RandomPlayers.exe` для запуску програми

### Спосіб 2: Через командний рядок

1. Відкрийте **Командний рядок** (cmd) або **PowerShell**
2. Перейдіть до папки з файлом:
   ```bash
   cd шлях\до\папки
   ```
3. Запустіть програму:
   ```bash
   .\ChitKvest-RandomPlayers.exe
   ```

### Спосіб 3: Клонування репозиторію

1. Відкрийте термінал і виконайте:
   ```bash
   git clone https://github.com/tima22863/it-step-project-.git
   ```
2. Перейдіть до папки проєкту:
   ```bash
   cd it-step-project-
   ```
3. Запустіть програму:
   ```bash
   .\ChitKvest-RandomPlayers.exe
   ```

## Можливі проблеми

### Windows SmartScreen блокує запуск
Якщо при запуску з'являється попередження Windows SmartScreen:
1. Натисніть **"Додаткові відомості"** (More info)
2. Натисніть **"Запустити в будь-якому разі"** (Run anyway)

### Антивірус блокує файл
Деякі антивіруси можуть хибно спрацьовувати на `.exe` файли. Додайте файл до виключень антивіруса, якщо ви впевнені у безпеці файлу.
